Angular consumes the <u-*> elements through the @universal-material/angular wrapper, which provides the ControlValueAccessors that make every form element work with [(ngModel)] and reactive forms. The raw elements also render in any Angular template once you allow custom tags with CUSTOM_ELEMENTS_SCHEMA. Install the element library and the Angular wrapper side by side. @universal-material/web ships the custom elements; @universal-material/angular adds the Angular form bindings. Import UniversalMaterialModule wherever you use the elements (a standalone component's imports, or a shared NgModule), import @universal-material/web once for its side effect so the <u-*> tags are registered, and add CUSTOM_ELEMENTS_SCHEMA so Angular accepts the custom tags. Add FormsModule for ngModel or ReactiveFormsModule for reactive forms. The wrapper registers a ControlValueAccessor for each form element, so [(ngModel)] binds them just like native controls: text fields, areas and search bind a string; checkbox and switch bind a boolean; radios contribute their value to the named group; u-select binds the option value; the slider binds a number; the datepicker binds an ISO date string; the chip field binds a string[]; and typeahead binds its current value. The same accessors power ReactiveFormsModule. Build a FormGroup and bind each element with formControlName — value, validation state and disabled all flow through the control. The template binds each <u-*> element with formControlName inside the [formGroup]. Besides binding the whole u-range-datepicker value (YYYY-MM-DD - YYYY-MM-DD) to a single control, each end of the range can bind to its own control — mirroring mat-date-range-input with matStartDate/matEndDate. Place two hidden carrier inputs with uStartDate and uEndDate inside the element; each binds an ISO date string. The element is only disabled when both controls are disabled. These snippets are distilled from the standalone Angular demo (checkbox, radio, select, text-field, search, slider, datepicker, chip-field and typeahead example pages) that the wrapper package was developed against. For the full set of components and live examples, see the universal-material-angular repository on GitHub.
