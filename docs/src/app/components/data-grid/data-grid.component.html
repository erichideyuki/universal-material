A fast, accessible data grid for large data sets, published as its own package, @universal-material/data-grid. It is a standard custom element built with Lit, so it works in plain HTML and in any framework. table_view Data grid documentation Live examples of every feature, with their source code and the full API arrow_outward
Highlights
  • Millions of rows with row and column virtualization.
  • Remote data: the server filters, sorts, groups, summarizes and pages; only visible blocks load.
  • Data shaping: multi-column sorting, filter row, search panel, header filters, grouping by drag and drop, summaries, tree data and master-detail.
  • Editing in cell, row and batch modes, with validation. Your items are never mutated.
  • Real-time updates with applyChanges() and reshapeOnChanges.
  • 14 languages built in, plus right-to-left layout.
  • Accessible: WAI-ARIA grid pattern, full keyboard support, WCAG 2.2 AA.
  • SSR and theming: renders with @lit-labs/ssr and reads the same --u-color-* tokens as the rest of Universal Material.
